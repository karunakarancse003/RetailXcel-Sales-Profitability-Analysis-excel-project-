# RetailXcel-Sales-Profitability-Analysis-excel-project-
RetailXcel – Sales &amp; Profitability Analysis (FY2021–2023) using Microsoft Excel. Analyzed 970 Orders and ₹4.92 Cr Revenue. Identified Revenue Gaps, 14.5% Return Rate, Discount Impact &amp; Product Profitability. Created KPI Dashboards using Pivot Tables to generate actionable business insights.
